# Implementação: Clonagem do Site Paraiba Explorer

## Objetivo
Replicação exata do site bio-link de Paraiba Explorer para fins de desenvolvimento e portabilidade.

## Arquivos Criados
- `paraiba-explorer/index.html`: Estrutura HTML com links e ativos originais.
- `paraiba-explorer/style.css`: Estilização Vanilla CSS com Design System baseado no original.

## Lógica e Dependências
- **Fontes**: Google Fonts (Anton, Open Sans, Arimo).
- **Ativos**: Links diretos para imagens hospedadas no domínio original para garantir fidelidade total.
- **Design**: Focado em Mobile-First, com efeitos de glassmorphism e hover suaves.
