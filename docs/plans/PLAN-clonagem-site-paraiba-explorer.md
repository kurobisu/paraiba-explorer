# PLAN-clonagem-site-paraiba-explorer

## Objetivo
Criar uma cópia exata do site `https://actourbc.com.br/paraiba-explorer`, focando em alta fidelidade visual, responsividade e funcionalidade de links.

## Análise do Site Alvo
- **Tipo:** Bio-link/Linktree (Provavelmente Canva).
- **Cores:** Amarelo (#E9D75D), Verde (#26D02D), Rosa (#E1598E), Azul (#299CE5).
- **Elementos Chave:** Cards com ícones 3D, botões "Saiba mais", logo centralizado, fundo amarelo vibrante.

## Arquivos Afetados
- `index.html`: Estrutura semântica do site.
- `style.css`: Estilização premium com CSS Vanilla.
- `assets/`: Imagens e ícones.

## Lógica de Implementação
1. **Estrutura HTML5**: Header, Main (com seção de cards) e Footer.
2. **Design System**: Definir variáveis CSS para cores e fontes.
3. **Cards Dinâmicos**: Criar componentes reutilizáveis para os cards de redes sociais.
4. **Responsividade**: Garantir que o design funcione perfeitamente em dispositivos móveis (foco principal deste tipo de site).
5. **Ativos**: Baixar o logo original e gerar ícones 3D semelhantes usando IA se necessário.

## Dependências
- Nenhuma (Vanilla JS/CSS).
