# PROJECT: Paraiba Explorer

## Visão Geral
**Paraiba Explorer** é uma landing page de alto impacto visual (estilo Linktree/Bio-link) para uma empresa de turismo em João Pessoa, Paraíba. O objetivo é centralizar o acesso às redes sociais (Instagram, TikTok, Facebook, Threads) e facilitar o contato direto via WhatsApp para reserva de passeios.

## Objetivos Estratégicos
- **Conversão:** Facilitar o contato via WhatsApp.
- **Identidade Visual:** Manter uma estética premium e moderna.
- **SEO/Social:** Garantir pré-visualizações perfeitas em redes sociais e WhatsApp.
- **Performance:** Carregamento rápido em dispositivos móveis.

## Stack Tecnológica
- **Linguagens:** HTML5, CSS3 (Vanilla).
- **Hospedagem:** GitHub Pages.
- **Domínio:** paraibaexplorer.com.br (Registro.br).

## Stakeholders
- **Proprietário:** Clóvis (NUC Tecnologia).
- **Desenvolvedor:** Antigravity (AI).

## Histórico do Projeto
- **Fase 01:** Clonagem e adaptação do layout base.
- **Fase 02:** Configuração de domínio customizado e CNAME.
- **Fase 03:** Implementação de Favicon, Open Graph e Meta Tags Sociais.
